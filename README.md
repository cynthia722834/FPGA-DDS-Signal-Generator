# 基于 Artix-7 FPGA 的多功能 DDS 数字信号发生器

基于 Xilinx Artix-7 FPGA 的多功能 DDS（直接数字频率合成）数字信号发生器，全部功能模块均为**手写 Verilog RTL 实现，零 IP 核依赖**。

## 功能特性

- **四种波形**：正弦波 / 方波 / 三角波 / 锯齿波
- **频率范围**：100Hz ~ 10MHz，理论分辨率 0.012Hz（32 位相位累加器）
- **双通道输出**：通道间相位差 0°/90°/180°/270° 可调
- **幅度四档**：25% / 50% / 75% / 100%
- **VGA 实时显示**：640×480@60Hz 三模式（示波器风格波形 / 李萨如图形 / 采集回显），内置 8×8 字符字库实现文字参数栏，波形周期数与频率联动、帧首尾无缝衔接
- **自动扫频**：一键遍历全频段
- **旋律播放**：内置《小星星》《生日快乐》，蜂鸣器与音频 PWM 双输出
- **按键交互**：单击步进、长按连加、按键提示音
- **XADC 采集回显**："发生器+示波器"二合一闭环演示

## 硬件平台

- 开发板：硬木课堂 ACE1-AR7（Xilinx Artix-7 XC7A35TFTG256-2）
- 板载资源：50MHz 晶振、6 位共阴数码管、12 路拨码开关、17 LED、4×4 矩阵键盘、VGA 接口（RGB444）、TLC7528 双通道 DAC、XADC、无源蜂鸣器

## 开发环境

- Vivado 2023.1 ML Standard
- Verilog HDL

## 目录结构

```
├── src/                  # 全部 RTL 源文件（10 个模块）
│   ├── top_dds.v         # 顶层
│   ├── dds_core.v        # DDS 内核（相位累加/双通道/四波形/幅度）
│   ├── wave_rom.v        # 4096×8 双端口正弦查找表
│   ├── freq_ctrl.v       # 频率控制（步进/长按连加）
│   ├── sweep_ctrl.v      # 扫频控制
│   ├── melody_player.v   # 旋律播放器（双曲目）
│   ├── debounce.v        # 按键消抖
│   ├── bin2bcd.v         # 二进制转 BCD
│   ├── seg7_display.v    # 数码管动态扫描
│   ├── vga_waveform.v    # VGA 三模式渲染引擎
│   ├── tlc7528_drv.v     # DAC 驱动
│   ├── sd_pwm.v          # Σ-Δ 调制器（音频）
│   └── xadc_cap.v        # XADC 采集
├── xdc/top_dds.xdc       # 引脚与时序约束
├── sim/tb_dds.v          # 测试平台（20 余项测试）
├── mem/                  # 正弦表初始化文件
├── docs/                 # 文档
├── build_project.tcl     # 一键构建（综合+实现+比特流）
├── program_board.tcl     # JTAG 烧录
└── sim_run.tcl           # 仿真运行
```

## 构建与烧录

```bash
# 构建（生成比特流）
vivado -mode batch -source build_project.tcl

# 烧录（连接板卡 JTAG 后）
vivado -mode batch -source program_board.tcl
```

## 操作说明

| 控制 | 功能 |
|---|---|
| SW1:0 | 波形选择（正弦/方波/三角/锯齿） |
| SW3:2 | 幅度档位（25%/50%/75%/100%） |
| SW5:4 | 双通道相位差（0/90/180/270°） |
| SW6+SW8 | 显示模式（00 波形 / 01 李萨如 / 1x 示波器） |
| SW7 | 自动扫频 |
| SW9 | 旋律播放 |
| SW10 | 歌曲切换（小星星/生日快乐） |
| KEY0/KEY1 | 频率 +/−（长按连加/连减） |
| KEY2 | 步进档位切换 |
| KEY3 | 复位 |
